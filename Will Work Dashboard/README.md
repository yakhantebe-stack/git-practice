# Game Server Administrator Dashboard

## Project Overview

The Game Server Administrator Dashboard is a web-based
dashboard used to monitor game servers, manage players
and view recent server activity.

## Features

- Displays all available game servers.
- Shows whether servers are online or offline.
- Displays player information in a table.
- Allows users to search for players by name.
- Allows users to filter players by server.
- Displays recent player activity.
- Allows users to filter activity by type.

## Technologies Used

- HTML5
- CSS3
- JavaScript
